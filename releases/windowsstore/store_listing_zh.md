简短描述:
本地PDF工作台：OCR、涂黑与格式转换。100%离线本地处理。

完整描述:
DokuZen 是专为 Windows 桌面设计的本地文档工作台。所有处理流程完全在您的设备本地运行——无需云端、无需账户、绝无数据传输。

核心功能:
- PDF 编辑：添加、删除、重新排序、合并与拆分页面。
- OCR 识别：扫描版 PDF 与图片的文字识别（基于 Tesseract 引擎，离线运行）。
- 安全涂黑：永久遮盖敏感与机密文本区域。
- 格式转换：PDF ↔ Word/DOCX，将图像转换为可搜索的 PDF。
- 文件库管理：带全文检索的文档库管理与即时预览。
- 批处理模式：同时自动化处理多个文档。

隐私与安全性:
无网络外联、无遥测上报、无隐藏后台进程。完全遵循 AGPL-3.0-or-later 开源协议。

系统要求:
Windows 10/11 (64 位)

关键字:
PDF, OCR, 文档管理, 涂黑, 转换, 隐私, 离线
