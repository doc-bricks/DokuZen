### Häufige Fragen

**Die Anwendung startet nicht.**
Stellen Sie sicher, dass Ihr System Windows 10/11 (64-bit) verwendet.
Prüfen Sie, ob das Microsoft Visual C++ Redistributable installiert ist.

**OCR liefert schlechte Ergebnisse.**
Stellen Sie sicher, dass das Eingabedokument eine Auflösung von mindestens
300 DPI hat. Bilder mit starkem Rauschen oder niedrigem Kontrast schränken die
OCR-Qualität ein.

**PDF-Konvertierung schlägt fehl.**
Einige passwortgeschützte oder DRM-gesicherte PDFs können nicht verarbeitet
werden. Entfernen Sie den Schutz, sofern Sie dazu berechtigt sind.

**Wo werden meine Einstellungen gespeichert?**
Der Bibliotheks- und Sitzungszustand liegt in `%USERPROFILE%\.dokuzen_state.json` (Windows).
Protokolldateien liegen im Unterordner `logs\` des Programmverzeichnisses.

## English

### Contact

For questions, bug reports, or suggestions:

- **GitHub Issues** (preferred): https://github.com/doc-bricks/DokuZen/issues
- **Email**: lukasgeiger@googlemail.com

### Frequently asked questions

**The application won't start.**
Make sure your system is Windows 10/11 (64-bit).
Check that the Microsoft Visual C++ Redistributable is installed.

**OCR produces poor results.**
Make sure the input document has a resolution of at least 300 DPI.
Images with heavy noise or low contrast reduce OCR quality.

**PDF conversion fails.**
Some password-protected or DRM-secured PDFs cannot be processed.
Remove the protection if you are authorised to do so.

**Where are my settings stored?**
Library and session state is kept in `%USERPROFILE%\.dokuzen_state.json` (Windows).
Log files are written to the `logs\` subfolder of the program directory.
