1. Executive Summary & Value Proposition
----------------------------------------
DokuZen is an all-in-one, local-first document and PDF desktop workstation built with Python 3.10-3.13
and PySide6. It consolidates 22 discrete document processing, conversion, OCR, and redaction utilities
into a single responsive interface, eliminating reliance on fragmented cloud SaaS tools and recurring
subscription fees while maintaining a strict 100% Zero-Egress and unprivileged security architecture.

2. Target Personas & High-Intent SEO Keywords

[PERSONA-01] Enterprise Privacy & Legal Compliance Auditors (GDPR / DSGVO, HIPAA, CCPA, ISO 27001)
- Context: Legal counsels, compliance teams, healthcare data processors, and corporate auditors.
- Pain Point: Cloud PDF platforms (Smallpdf, iLovePDF) transmit confidential documents, PII, and client
  records to third-party servers, causing severe compliance breaches and data leaks.
- DokuZen Solution: Guaranteed local processing (Zero-Egress), irreversible vector and raster black-fill
  redaction, and non-elevated user-mode execution.
- High-Intent SEO Queries:
  * "local pdf redaction tool gdpr compliant"
  * "offline pdf pii sanitizer"
  * "desktop document anonymizer zero data egress"
  * "safe legal document redaction software"

[PERSONA-02] Desktop Power Users, Paralegals & Office Professionals
- Context: Paralegals, administrative assistants, educators, and office workers managing heavy PDF workflows.
- Pain Point: Adobe Acrobat Pro recurring subscriptions ($240+/year), slow application startup, bloated
  background services, and disconnected single-purpose utilities.
- DokuZen Solution: Unified 22-in-1 tool suite, fast multi-page PyMuPDF preview, global keyboard shortcuts
  (Ctrl+I, Ctrl+F, Ctrl+P), batch operations, and transparent PNG signature stamping.
- High-Intent SEO Queries:
  * "free alternative to adobe acrobat pro offline"
  * "fast desktop pdf merger and splitter"
  * "pyside6 document manager"
  * "pdf signature overlay desktop tool"

[PERSONA-03] Open-Source Researchers, Archivists & Academics
- Context: Researchers, librarians, historical archivists, and graduate students cataloguing vast paper collections.
- Pain Point: Poor OCR searchability in scanned PDFs, missing metadata taxonomy, character encoding corruption
  (Mojibake), and fragmented storage.
- DokuZen Solution: Tesseract OCR integration with multi-language bounding-box accuracy, persistent thematic
  category indexing, read/unread review progress tracking, and Mojibake encoding restoration.
- High-Intent SEO Queries:
  * "open source ocr pdf search tool"
  * "academic document organizer local first"
  * "tesseract ocr desktop gui python"
  * "scan to searchable pdf offline"

[PERSONA-04] Automation Engineers & Ecosystem Integrators
- Context: DevOps engineers, system administrators, and Python developers building local document pipelines.
- Pain Point: Brittle cloud REST APIs, platform-specific lock-in, non-deterministic file descriptor leaks,
  and complicated packaging.
- DokuZen Solution: Portable packaging (Windows Store MSIX + Linux PyInstaller bundle), headless CLI entry
  shortcuts (--import, --ocr, --redact, --merge), standardized dokuzen-workspace-v1.json export schema.
- High-Intent SEO Queries:
  * "portable linux pdf tools bundle"
  * "python pdf automation local-first"
  * "msix python desktop app"
  * "reproducible offline document workflow"
